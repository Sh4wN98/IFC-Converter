IFC Converter {version} – Kurzanleitung

IFC-Gebäudemodelle nach Rhino (3DM), GLB, OBJ und DAE konvertieren · Probephase im Büro · English version on page {english_page}

1. Was das Programm macht

Der IFC Converter wandelt IFC-Dateien (IFC2x3, IFC4, IFC4.3; auch IFC2x2 und der IFC4x4-Entwurf, gepackte .ifczip) in 3D-Formate um: Rhino .3dm (Polyflächen oder Netze, Layer nach Geschoss und Bauteilklasse, Bauteildaten als Benutzertext), GLB, OBJ und DAE. Die Ausgabe ist immer in Metern, Lage und Maße entsprechen exakt der IFC. Die IFC-Datei selbst wird nie verändert, vorhandene Ausgabedateien werden nie überschrieben.

2. Installation

  • Installer: IFC-Converter-{version}-Setup.exe doppelklicken. Keine Administratorrechte nötig, installiert wird nur für den angemeldeten Benutzer. Ein Update ist derselbe Weg mit der neuen Version; Einstellungen bleiben erhalten.
  • Ohne Installation: IFC-Converter-{version}-portable.zip entpacken und IFC Converter.exe starten.
  • Windows SmartScreen: Das Programm ist nicht signiert. Beim ersten Start „Weitere Informationen“ → „Trotzdem ausführen“ wählen.
  • Linux: IFC-Converter-{version}-linux-x86_64.tar.gz entpacken, ./install.sh ausführen.

3. Erste Schritte

Das Programmfenster: Dateiliste und Vorschau links, Zielformat und Speicherort rechts, Protokoll unten.

  1. IFC-Dateien oder ganze Ordner in das Fenster ziehen (oder „Dateien hinzufügen…“). Die 3D-Vorschau baut sich auf, während sie berechnet wird: tragende Struktur zuerst, Möbel und Haustechnik bleiben weg.
  2. Rechts das Zielformat wählen. Für Rhino: Polyflächen (echte Öffnungen, bearbeitbar, 1,2–4,5× größere Datei) oder Netze (kleinste Datei, schnellste Umwandlung – bei sehr großen Modellen die bessere Wahl).
  3. Speicherort prüfen (Standard: Desktop) oder „Neben der IFC-Datei speichern“.
  4. Konvertieren klicken. Der Fortschritt steht je Datei in der Liste, „Ausgabeordner öffnen“ führt zum Ergebnis.

Nur Gebäudehülle

Das Häkchen „Nur Gebäudehülle“ wandelt nur um, was von außen zu sehen ist: Außenwände, Dächer, Fenster, Türen, Balkone, Gelände. Innenwände, Decken, Möbel, Sanitär und Leitungen bleiben weg. Die Datei wird dadurch deutlich kleiner – gedacht für Umgebungsmodelle und schwächere Rechner. Glas gilt dabei als undurchsichtig. Bei kleinen Modellen dauert die Umwandlung damit etwas länger (ein grober Durchgang bestimmt zuerst die Hülle).

Weitere Einstellungen (Extras → Einstellungen)

  • Leistung: Threads und Priorität. Standard: etwa die halbe Maschine mit niedriger Priorität, damit andere Programme flüssig bleiben.
  • Geometriekern: „Genau“ (Standard) lassen.
  • Ausgabe: „Gleiche Bauteile als Blöcke“ macht Rhino-Dateien 20–45 % kleiner; Blockinstanzen müssen zum Bearbeiten in Rhino erst aufgelöst werden (_Explode).

5. Sprache

Menü Extras → Sprache (englisch: Tools → Language). Nach der Wahl bietet das Programm einen Neustart an. Verfügbar: Deutsch, Englisch, Französisch, Spanisch, Italienisch, Portugiesisch, Niederländisch, Polnisch, Türkisch. Beim ersten Start ist die Oberfläche englisch.

6. Wenn etwas nicht klappt – Rückmeldung mit Logdatei

So gibst du eine Rückmeldung:

  1. Im Programm Hilfe → „Anonymisierte Logdatei speichern…“ wählen und die Datei speichern.
  2. Bei sichtbaren Problemen (fehlende Teile, falsche Lage) einen Screenshot aus Rhino bzw. dem Zielprogramm machen.
  3. Beides zusammen mit einem Satz dazu („Datei X, Netze, nur Hülle – Fenster fehlen im Erdgeschoss“) an Jonas schicken.

Die anonymisierte Logdatei enthält keine Benutzer-, Rechner-, Server-, Ordner-, Datei- oder Bauteilnamen – nur Zeiten, Größen, Zahlen und die Meldungen des Programms. Sie bleibt auf deinem PC, bis du sie selbst weitergibst. Wer dauerhaft anonym protokollieren will: Extras → Einstellungen → Logdatei → „Logdatei anonymisieren“.

  • „Übersprungene Bauteile…“ (Rechtsklick auf eine fertige Datei): listet Bauteile, die nicht umgewandelt werden konnten, mit Klasse und GlobalId zum Kopieren.
  • Absturz oder Hänger: Das Programm startet die Umwandlung selbst neu, grenzt das betroffene Bauteil ein und überspringt es; bereits berechnete Teile werden übernommen. Im Protokoll steht, was passiert ist.
  • Sehr große Modelle (über 1 GB): Rhino-Netze statt Polyflächen wählen und genug freien Speicherplatz auf C: lassen; Ausgaben auf Netzlaufwerke werden erst lokal geschrieben und dann kopiert.
  • ifcXML kann nicht gelesen werden – im Autorenprogramm als .ifc oder .ifczip exportieren.

7. Kommandozeile (optional)

Neben dem Programm liegt ifc-convert.exe: ifc-convert haus.ifc -f 3dm -g mesh, ifc-convert *.ifc -d ausgabe\, Optionen --envelope (nur Hülle), --blocks, --lang de. ifc-convert --help zeigt alles.

IFC Converter {version} – Quick Guide

Convert IFC building models to Rhino (3DM), GLB, OBJ and DAE · office trial

1. What it does

The IFC Converter turns IFC files (IFC2x3, IFC4, IFC4.3; also IFC2x2 and the IFC4x4 draft, packed .ifczip) into 3D formats: Rhino .3dm (polysurfaces or meshes, layers by storey and element class, element data as user text), GLB, OBJ and DAE. Output is always in metres; positions and dimensions match the IFC exactly. The IFC file is never modified and existing output files are never overwritten.

2. Installation

  • Installer: double-click IFC-Converter-{version}-Setup.exe. No administrator rights needed; it installs for the signed-in user only. Updating is the same step with the new version; settings are kept.
  • Without installing: unpack IFC-Converter-{version}-portable.zip and start IFC Converter.exe.
  • Windows SmartScreen: the program is not code-signed. On first start choose “More info” → “Run anyway”.
  • Linux: unpack IFC-Converter-{version}-linux-x86_64.tar.gz and run ./install.sh.

3. Getting started

The window: file list and preview on the left, output format and folder on the right, log at the bottom.

  1. Drag IFC files or whole folders into the window (or “Add files…”). The 3D preview builds up while it is computed: structure first, furniture and MEP are left out.
  2. Pick the output format on the right. For Rhino: Polysurfaces (real openings, editable, 1.2–4.5× larger file) or Meshes (smallest file, fastest conversion – the better choice for very large models).
  3. Check the output folder (default: Desktop) or tick “Save next to the IFC file”.
  4. Click Convert. Progress is shown per file; “Open output folder” takes you to the result.

Only the building hull

The checkbox “Only the building hull” converts only what is seen from outside: exterior walls, roofs, windows, doors, balconies, terrain. Interior walls, floors, furniture, sanitary fittings and building services are left out, so the file gets much smaller – meant for context models and weaker PCs. Glass counts as opaque. On small models the conversion takes somewhat longer (a coarse pass determines the hull first).

More settings (Tools → Settings)

  • Performance: threads and priority. Default: about half the machine at low priority, so other programs stay responsive.
  • Geometry kernel: leave “Accurate” (default).
  • Output: “Identical elements as blocks” makes Rhino files 20–45 % smaller; block instances must be exploded in Rhino before editing (_Explode).

Without graphics acceleration (remote desktop, virtual machine) the program draws in software automatically.

5. Language

Menu Tools → Language. After choosing, the program offers to restart. Available: English, German, French, Spanish, Italian, Portuguese, Dutch, Polish, Turkish. The first start is in English.

6. When something goes wrong – feedback with the log file

How to give feedback:

  1. In the program choose Help → “Save anonymised log file…” and save the file.
  2. For visible problems (missing parts, wrong position) take a screenshot in Rhino or the target program.
  3. Send both with one sentence (“file X, meshes, hull only – windows missing on the ground floor”) to Jonas.

The anonymised log contains no user, computer, server, folder, file or element names – only times, sizes, numbers and the program’s messages. It stays on your PC until you pass it on yourself. To log anonymously all the time: Tools → Settings → Log file → “Anonymise log file”.

  • “Skipped elements…” (right-click a finished file): lists elements that could not be converted, with class and GlobalId to copy.
  • Crash or hang: the program restarts the conversion itself, isolates the element concerned and skips it; parts already computed are taken over. The log says what happened.
  • Very large models (over 1 GB): choose Rhino meshes instead of polysurfaces and leave enough free space on C:; output to network drives is written locally first and then copied.
  • ifcXML cannot be read – export as .ifc or .ifczip from the authoring program.

7. Command line (optional)

Next to the program there is ifc-convert.exe: ifc-convert house.ifc -f 3dm -g mesh, ifc-convert *.ifc -d output\, options --envelope (hull only), --blocks, --lang de. ifc-convert --help lists everything.
